# aBot 机器人动作探索（和爸爸妈妈一起玩）

> 适合：8 岁左右的小朋友 ｜ 一起做：家长读、孩子玩 ｜ 需要：装好 Blender 的电脑

嗨！欢迎来玩 aBot 机器人。它是一个用电脑做出来的小机器人，住在一个叫 Blender 的"积木世界"里。这个手册会带你和爸爸妈妈一起，让机器人**动起来**，看看它都会做什么。

---

## 第 1 关：机器人是怎么动的？

机器人和我们一样，靠"骨头"和"关节"来动。

- **骨骼（Bones）**：就像我们的骨头。aBot 有 **19 根骨头**——头、脖子、身体、两只手臂（上下两截）、两条腿、脚……
- **关节（Joints）**：骨头和骨头之间能转动的地方，就像你的手腕、胳膊肘、膝盖。
- **动作（Action）**：让好多骨头一起动，就变成"动作"。比如挥手=肩膀动+胳膊肘弯+手摆一摆。

> 想一想：你挥手的时候，是哪些关节在动？和机器人挥手时一样吗？

---

## 第 2 关：我们的小机器人会做什么？

它已经学会了 **9 个动作**，我们把它们画在下面。每个动作都有一张照片（`assets/humanoid/action_*.png`），你可以打开对照看。

| 动作 | 是什么 | 你会看到 |
|---|---|---|
| `relax` | 放松站好 | 手垂在两边，像发呆 |
| `tpose` | 站成"T"字 | 两只手平平伸开，像飞机 |
| `apose` | 站成"A"字 | 手斜斜向下，像字母 A |
| `idle` | 等待（呼吸） | 身体轻轻一起一伏 |
| `wave` | 挥手打招呼 | 右手举起来摇一摇（**右**手哦！） |
| `walk` | 走路 | 一条腿向前，另一条腿在后 |
| `nod` | 点头 | 头低下来点一点 |
| `look` | 左右看 | 头转到旁边看 |
| `run` | 跑步 | 比走路更快、腿抬更高 |

> 想一想：`walk` 和 `run` 哪里不一样？`tpose` 和 `apose` 的手差别在哪？

## 第 3 关：让机器人动起来（操作步骤）

1. 请爸爸妈妈帮你打开 Blender，然后打开我们的机器人文件：
   `assets/humanoid/humanoid.blend`
2. 按下键盘的 **空格键**（空格 = 播放）。你会看到机器人开始"呼吸"（这是 `idle` 动作）。
3. 想换动作？这样做：
   - 点击中间的机器人（选中它）
   - 在窗口上方把模式换成 **Dope Sheet**，再选 **Action Editor**
   - 在下拉框里选 `ActionWalk`、`ActionWave`、`ActionRun`……
   - 再按空格键播放，机器人就做新动作啦！
4. 如果动作只做一半，把时间轴末尾的时间调长一点（比如到 200 帧），就能完整播放、循环播放。

> 如果哪里不会，就喊爸爸妈妈帮忙——一起探索才好玩。

## 第 4 关：探索任务卡（每完成一个就贴一颗星 ★）

### 任务 1：谁在动？★
播放 `wave`，暂停在挥手那一下。问爸爸妈妈（或自己找）：**是左手还是右手举起来了？**（提示：照片 `action_wave.png` 里，举起的是屏幕左边的手=机器人的**右手**）

### 任务 2：找不同 ★
先播 `walk`，再播 `run`。说说跑步和走路**有哪里不一样**（腿抬多高？有没有往前倾？）

### 任务 3：让它点头又摇头 ★
先把动作换成 `nod` 播放，再换 `look` 播放。`nod` 是**点头**（上-下），`look` 是**转头看旁边**（左-右）。试试能不能让机器人先点头、再看你。

### 任务 4：指挥机器人 ★
看完这 9 个动作，你来当"小指挥"：爸爸妈妈随机报一个动作名，你负责把它切换出来并播放。全对就集齐一颗星！

### 任务 5：给它拍张照 ★
选一个你最喜欢的动作，请爸爸妈妈帮你把它截图/拍下来，存到 `assets/humanoid/` 里，命名 `my_favorite_action.png`。这就是**你的作品**。
